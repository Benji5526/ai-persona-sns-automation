# 13. 파일럿 실행 계획 (1~2개월)

저장소: https://github.com/Benji5526/ai-persona-sns-automation

> [11-recommended-sequence.md](11-recommended-sequence.md) 2~3단계("수동 파일럿" → "콘텐츠 파이프라인 검증")를
> 실제로 무엇을, 어떤 도구로, 얼마 동안, 얼마의 예산으로 진행할지 구체화한 문서입니다.
> 하드웨어 구매([12-hardware-spec.md](12-hardware-spec.md)) 전에 이 파일럿부터 완료하는 것을 전제로 합니다.

## 1. 목표 및 성공 기준

**검증 질문**: 이 페르소나 컨셉이 실제로 반응을 얻는가, 그리고 운영이 지속 가능한가.

| 구분 | 지표 |
|---|---|
| 정량 | 팔로워 증가율, 게시물당 평균 참여율(좋아요+댓글+저장/도달), DM 문의 수 및 응답 후 전환 |
| 정성 | 본인이 이 페르소나를 매주 운영하는 게 즐겁고 지속 가능한지 (주관식 기록) |
| 중단 기준 | 8주 후에도 참여율이 계정 카테고리 평균 이하이고 개선 추세가 없으면 컨셉 재검토 — 이 시점에는 자동화·하드웨어 투자 보류 |

## 2. 범위 — 자동화 최소화

[11-recommended-sequence.md](11-recommended-sequence.md)의 원칙(수동 파일럿에는 자동화를 넣지 않는다)을 유지하되,
콘텐츠 제작 보조 도구로 저비용 API/온디맨드 자원만 사용합니다.

- **이미지**: ComfyUI 로컬 설치 없이 클라우드 GPU를 필요할 때만 온디맨드로 켜서 배치 생성 (아래 4번)
- **캡션/DM 응답 초안**: 저비용 LLM API로 초안만 생성, **최종 검수·발행은 항상 사람이 수동으로** 수행
- **포스팅**: 자동 포스팅 없음, 수동 게시

## 3. 저비용 LLM API 비교 (캡션·응답 초안용)

| 제공사 / 모델 | 가격 (입력/출력, $/MTok) | 비고 |
|---|---|---|
| Claude Haiku 4.5 | $1.00 / $5.00 | Anthropic 공식 요금 [[1]](#ref1) |
| GPT-4o mini | $0.15 / $0.60 | [[2]](#ref2) |
| Gemini 3.1 Flash-Lite | $0.25 / $1.50 (2026-10-16 이후 최저가 라인업) | [[2]](#ref2) |

**파일럿 규모(월 100건 내외, 건당 수백 토큰)에서는 어느 쪽을 선택해도 월 $1 미만입니다.**
가격보다 **페르소나가 실제로 게시할 언어에서의 톤 품질**과 **연동 편의성** 기준으로 선택하는 것이 합리적입니다.
자체 LLM 서버([09-llm-serving.md](09-llm-serving.md))는 이 단계에서 아직 불필요합니다.

## 4. 클라우드 GPU 사용 방식 (이미지, 필요시에만)

- 상시 구동 없음 — 주 1회 정도, 필요한 이미지 물량을 한 번에 생성할 때만 RunPod/Vast.ai 인스턴스를 켬
- 세션당 1~2시간이면 파일럿에 필요한 물량(주 5~10장) 처리 가능
- [10-budget-simulation.md](10-budget-simulation.md)의 단가 기준(RTX4090급 $0.35/hr) 적용 시 월 4~8시간 사용 = **월 $1.4~2.8**
- ComfyUI 세팅이 부담되면 파일럿 초반에는 이미지 생성 없이 문구/컨셉 중심 콘텐츠로 시작해도 무방 — 이미지 품질 검증은 이 단계의 목적이 아님

## 5. 파일럿 예산 요약 (월 기준)

| 항목 | 월 비용 |
|---|---|
| LLM API (캡션/DM 초안) | < $1 |
| 클라우드 GPU (이미지, 주 1회) | $1.4~2.8 |
| SNS API | [10-budget-simulation.md](10-budget-simulation.md) 기준 사실상 $0 |
| **합계** | **월 $10 미만** |

하드웨어 구매(650만원~, [12-hardware-spec.md](12-hardware-spec.md)) 전에 월 1만원 미만으로 핵심 가설을 검증할 수 있다는 것이 이 계획의 요점입니다.

## 6. 타임라인 (예시 8주)

| 주차 | 내용 |
|---|---|
| 1~2주 | 페르소나 캐릭터 시트 확정([06-data-model.md](06-data-model.md)), 계정 개설/워밍업, 초기 콘텐츠 10개 준비 |
| 3~6주 | 주 2~3회 게시 + DM/댓글 수동 응대(LLM 초안 활용), 반응 기록 |
| 7~8주 | 데이터 취합, 참여율 추이 분석, 지속 여부 판단 |

## 7. 측정 방법

별도 대시보드 없이 간단한 스프레드시트로 충분합니다.

- 게시물별 도달/참여율, 팔로워 증가 추이
- DM 문의 수 및 전환 여부
- 본인의 운영 피로도 (주 1회 주관식 메모 — "이번 주 운영이 재미있었는가")

## 8. 다음 단계 전환 기준

- **명확한 상승 추세 + 본인 만족** → 3단계(콘텐츠 파이프라인, [02](02-model-training.md)~[05](05-auto-posting.md)) 착수,
  [12-hardware-spec.md](12-hardware-spec.md) 하드웨어 검토 시작
- **애매하거나 하락** → 페르소나 컨셉/타겟을 재조정해 재파일럿 (자동화·하드웨어 투자는 계속 보류)
