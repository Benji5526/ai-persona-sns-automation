# 10. 예상 예산 시뮬레이션

저장소: https://github.com/Benji5526/ai-persona-sns-automation

> 이 문서는 설계 단계의 개략적 견적(order-of-magnitude estimate)입니다. 실제 값은 모델 선택,
> 해상도, GPU 가용성에 따라 크게 달라질 수 있습니다. Phase 2~4([08-roadmap.md](08-roadmap.md))
> 진입 전 실측으로 재검증을 권장합니다.
>
> **UGC 원본 구매 비용은 이 시뮬레이션에서 제외했습니다.** 소싱처·라이선스 범위에 따라 편차가 너무 커서
> 일반화된 단가를 매기기 어렵습니다 — 실제 소싱처 견적을 받아 아래 총액에 별도로 더해야 합니다.
> 여기서는 UGC 페이스스왑의 **컴퓨트 비용만** 반영합니다.

## 1. 시뮬레이션 범위

[09-llm-serving.md](09-llm-serving.md)의 로컬 LLM과 [02](02-model-training.md)~[05](05-auto-posting.md)의
이미지/영상 생성·페이스스왑·자동 포스팅 파이프라인을 실제로 연결해 운영했을 때의 **월간 예산**을 추정합니다.

**공통 전제**: 콘텐츠는 페르소나당 1회 생성해 인스타그램·스레드·X·TikTok 4개 플랫폼에 **크로스 포스팅**한다고 가정합니다
(플랫폼별로 별도 생성하면 생성 비용이 최대 4배가 됩니다 — 아래 5번 참고).

| 시나리오 | 페르소나 수 | 월 콘텐츠 수 (이미지/영상) | 대화 자동화 | 비고 |
|---|---|---|---|---|
| **Small** (테스트) | 1 | 10건 (7이미지 + 3영상) | 없음 (사람이 직접 응대) | 파이프라인 검증 단계 |
| **Medium** (정상 운영) | 1 | 30건 (20이미지 + 10영상, 그중 UGC 페이스스왑 5건) | 있음 (LLM 상시 구동) | [로드맵](08-roadmap.md) Phase 3~4 |
| **Large** (스케일아웃) | 3 | 90건 (페르소나당 30건 동일 비율) | 있음 (멀티 LoRA 상시 구동) | Phase 6 |

## 4. 시나리오 비교 (UGC 원본 구매 비용 제외)

| 시나리오 | 클라우드 GPU 상시구동 | 자체 GPU 상시구동 |
|---|---|---|
| Small (자동화 없음, 테스트) | ~$1 (LLM 상시구동 없음) | ~$1 |
| Medium (1페르소나) | ~$260 | ~$35~40 |
| Large (3페르소나) | ~$730 | ~$60~85 |

> Large 시나리오는 LLM 서버를 멀티 LoRA로 확장하면서 GPU 사양을 한 단계 올린다고 가정
> (예: A100급 상시 구동, 클라우드 기준 ~$720/월, 자체 GPU 전기요금 ~$60~80/월).
> 실제 총 예산은 여기에 **UGC 원본 구매 비용**(사용하는 경우)을 소싱처 견적대로 더해야 합니다.

## 5. 비용 구조에서 읽어야 할 것

1. **이미지/영상 생성 자체는 거의 공짜에 가깝다.** Medium 시나리오에서 순수 생성 컴퓨트는 월 $1 미만입니다.
   병목은 생성이 아니라 아래 2번 항목입니다.
2. **가장 큰 고정비는 "LLM 상시 구동" 방식이다.** 클라우드 GPU를 24/7 대여하면 이 항목 하나가
   전체 예산의 70~90%를 차지합니다. [09-llm-serving.md](09-llm-serving.md)에서 지적한 대로,
   지금 규모(저동시성 대화 자동화)에서는 vLLM + 클라우드 상시 대여보다
   **자체 GPU 보유(전기요금만) 또는 더 가벼운 로컬 서빙(llama.cpp/Ollama)** 이 압도적으로 경제적입니다.
3. **UGC 원본 구매 비용은 이 시뮬레이션에 포함되지 않았다.** 소싱처·라이선스 범위에 따라 편차가 커서
   일반화하기 어렵고, 실제로는 물량이 늘면 LLM 상시구동 비용을 넘어서는 항목이 될 가능성이 있습니다.
   실제 소싱처 견적을 받으면 위 합계에 별도로 더해서 재계산해야 합니다.
4. **SNS API 비용은 사실상 무시할 수준이다.** X API가 2026년 종량제로 바뀌면서 소량 포스팅은
   게시글당 $0.015로 매우 저렴해졌고 (과거 월 $200 Basic 요금제 기준보다 훨씬 저렴), Meta/TikTok은
   달러 비용이 아니라 **앱 심사·오디트 승인 시간**이 진짜 비용입니다.
5. **크로스 포스팅 가정이 깨지면 생성 비용이 배수로 늘어난다.** 플랫폼마다 별도 콘텐츠를 생성하면
   1번 항목의 비용이 최대 4배가 되지만, 여전히 절대 금액은 작습니다 (LLM 상시구동 비용에 비하면).

## 6. 검증이 필요한 항목

- [ ] 실제 사용할 영상 생성 모델의 GPU 시간 실측 (모델·해상도·프레임 수에 따라 3~5배 차이 가능)
- [ ] 거주 지역 전기 요금 기준 자체 GPU 상시 구동 비용 재계산
- [ ] 실제 UGC 소싱처 견적 확보 후 위 합계에 별도 반영 (이 시뮬레이션에서 제외된 항목)
- [ ] Meta/TikTok 앱 심사 통과 여부 및 소요 기간 (비용은 $0이나 일정 리스크)
- [ ] X API 종량제 요금이 링크 포함 게시물($0.20/건)로 바뀔 경우 재계산
