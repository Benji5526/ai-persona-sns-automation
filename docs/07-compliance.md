# 07. 운영·윤리·법적 고려사항

저장소: https://github.com/Benji5526/ai-persona-sns-automation

이 시스템은 기술적으로는 충분히 구현 가능하지만, **플랫폼 정책·초상권·소비자 보호 규제**와
맞닿는 지점이 많습니다. 설계 초기에 반영해야 나중에 파이프라인을 뜯어고치지 않아도 됩니다.

## 0. 관할권 프레임 — "회사 소재지"와 "이용자 소재지"는 다른 문제

이 서비스는 조지아(국가)에서 운영되지만, **특정 국가를 타겟팅하지 않는 글로벌 자연 유입** 모델입니다.
이 조합에서는 규제 적용을 두 축으로 나눠 생각해야 합니다.

| 축 | 기준 | 적용 규제 | 상세 |
|---|---|---|---|
| ① 회사측 의무 | 처리 주체(회사)의 소재지 = 조지아 | 조지아 개인정보보호법, 조지아 세법 | [15-entity-and-tax.md](15-entity-and-tax.md) |
| ② 콘텐츠 발행 시 의무 | 콘텐츠가 도달하는 이용자 소재지 = 불특정 다수/전세계 | EU AI Act(역외적용), 각국 딥페이크·소비자보호법 | 아래 2번 |

**"조지아에 회사가 있다"는 사실은 ①만 정리해줄 뿐, ②를 면제해주지 않습니다.** 자연 유입 모델에서는
어느 이용자가 어느 나라에 있을지 사전에 알 수 없으므로, 국가별로 개별 대응하는 것은 애초에 불가능합니다.
따라서 ②는 **"어느 나라 이용자가 봐도 문제없는 최소 공통 기준"을 기본값으로 설계**하는 것이 유일하게
현실적인 전략입니다 (2번 참고).

## 1. 플랫폼 자동화 정책

- 각 SNS의 API 이용약관은 "자동 대량 발송/댓글/DM"에 대한 제한을 명시하는 경우가 많음 → 공식 API·공식 자동화 프로그램(비즈니스 메시징 API 등) 우선 검토
- 비공식(스크래핑/역엔지니어링 기반) 자동화는 계정 정지·법적 리스크가 있으므로 지양
- 플랫폼 ToS는 **회사 소재지와 무관하게 전세계 공통 적용** — 조지아 법인이라고 예외가 생기지 않음
- 플랫폼별 "AI 생성 콘텐츠 라벨링" 기능(있는 경우) 적용 검토

## 2. AI 생성/합성 콘텐츠 고지 — 선택이 아니라 기본값

타겟 국가가 없는 자연 유입 모델에서는 EU 이용자·미국 이용자 유입이 사실상 필연입니다.
EU AI Act는 **"AI 시스템의 결과물이 EU 내에서 사용되면"** 제공자 소재지와 무관하게 적용되는
역외적용 규제이고(합성 콘텐츠 라벨링 의무 포함), 미국은 다수 주가 AI 생성 콘텐츠·딥페이크 공시
의무법을 개별적으로 두고 있습니다. 50개 주·수십 개 법역을 하나하나 대응하는 것은 비현실적이므로:

- **"AI/합성 콘텐츠임을 항상 표시"하는 것을 시스템 기본값으로 설계**합니다 — 이게 대부분의 개별
  법역 요건 취지를 동시에 충족시키는 유일한 실무적 방법입니다
- [06-data-model.md](06-data-model.md)의 `asset.source` 필드로 **무엇이 합성물인지 항상 추적 가능**하게 하고,
  라벨링을 온오프 스위치가 아니라 **디폴트 온(on)**으로 설계
- 페르소나가 "실존 인물처럼" 사람들과 상호작용(DM/댓글)할 경우, 계정 소개/고정 게시물 등에
  가상 캐릭터임을 고지 — 완전 비공개 운영은 규제 리스크가 더 큼

## 3. 얼굴교체·모션 리타겟팅 관련 초상권 — 영상 출처국 기준

- [04-faceswap-ugc.md](04-faceswap-ugc.md)(얼굴교체 엔진), [14-motion-reenactment.md](14-motion-reenactment.md)(모션 리타겟팅)
  둘 다 권리 확인 게이트가 핵심 방어선
- "영상 사용권 구매" ≠ "해당 영상 속 인물 얼굴을 교체/재생성할 권리" — 계약서에 **합성/변형 후 재배포**가
  명시적으로 포함되는지 반드시 확인
- **이 의무는 영상이 촬영·제작된 국가와 등장인물의 권리에 따르며, 회사 소재지(조지아)나 이용자
  소재지와 무관합니다.** UGC·드라이빙 영상을 어느 나라에서 소싱하든 그 출처국 기준으로 별도 검토 필요
- 라이선스 범위가 모호한 소스는 법률 검토 없이 파이프라인에 투입하지 않음

## 4. 개인정보/대화 데이터 (조지아 개인정보보호법 기준)

- 회사가 조지아 소재이므로, DM/댓글 대화 이력에 포함된 개인정보는 **이용자 국적과 무관하게 조지아
  개인정보보호법(Law of Georgia on Personal Data Protection)이 최소 기준으로 적용**
- 2026-03-02부터 감독기관이 국가감사원(State Audit Office)으로 이관됨 — 데이터 유출 시 **72시간 내
  국가감사원 신고 의무**
- 보관 기간, 접근 권한, 파기 정책을 사전에 정의
- 페르소나 학습에 사용하는 레퍼런스 이미지가 본인 소유가 아닌 경우, 별도의 사용 동의/라이선스 확보 필요
- 법인/세제 구조 상세: [15-entity-and-tax.md](15-entity-and-tax.md)

## 5. 상업적 표시 규제

- 홍보/판매 목적의 콘텐츠라면 광고 표시 의무(협찬/광고 표기 등) 준수 — 이 역시 국가별로 다르므로
  2번과 같은 논리로 **가장 보수적인 표시 관행을 기본값**으로 적용
- 페르소나를 통한 판매 유도 대화(DM)의 경우, 소비자 보호 관련 고지 의무 여부 검토

## 6. 설계에 반영된 완화 장치 요약

| 리스크 | 완화 장치 (관련 문서) |
|---|---|
| 스팸/계정 정지 | 휴먼라이크 스케줄러의 동시성/총량 상한 ([01](01-reply-automation.md)) |
| 무단 초상권 사용 (영상 출처국 기준) | UGC/드라이빙 영상 권리 확인 게이트 + 라이선스 레코드 강제 연결 ([04](04-faceswap-ugc.md), [14](14-motion-reenactment.md), [06](06-data-model.md)) |
| 저품질/오작동 콘텐츠 확산 | QC 게이트 (자동+수동) ([03](03-content-pipeline.md), [04](04-faceswap-ugc.md), [14](14-motion-reenactment.md)) |
| 다국가 합성물 고지 의무 미준수 | AI 라벨링을 선택이 아닌 기본값으로 설계 ([06](06-data-model.md)) |
| 완전 자동 발행 리스크 | 반자동(승인 후 발행)으로 단계적 도입 ([05](05-auto-posting.md), [08](08-roadmap.md)) |
| 조지아 개인정보보호법 미준수 | 72시간 유출 신고 프로세스 사전 정의 ([15](15-entity-and-tax.md)) |

> 이 문서는 일반적인 설계 가이드이며 법률 자문을 대체하지 않습니다. 특히 "글로벌 자연 유입, 타겟
> 국가 없음"이라는 전제는 실제 운영 중 특정 지역 팔로워층이 뚜렷해지면 재검토가 필요합니다
> (예: 팔로워의 다수가 특정 국가로 쏠리면 그 국가 규제를 개별적으로 다시 확인).
> 실제 착수 전 조지아 현지 변호사와 함께 개인정보보호법·세제·(존재한다면) AI 관련 규제를,
> 목표 플랫폼 이용자층이 뚜렷해지면 해당 지역 변호사와 소비자보호·광고표시법을 검토하는 것을 권장합니다.
