# 08. 단계별 구축 로드맵

저장소: https://github.com/Benji5526/ai-persona-sns-automation

> **MVP는 대화 자동화도 콘텐츠 자동화도 아닙니다.** README의 [MVP](../README.md#mvp-최소-기능-제품) 정의에 따라,
> 아래 Phase 1~6은 전부 **MVP를 통과한 이후**의 확장 단계입니다. 두 축(대화 자동화 / 콘텐츠 자동화)은
> Phase 1~2부터 병렬 진행 가능하지만, MVP 자체는 두 축 모두 자동화하지 않습니다.

## MVP — 기반 준비 + 수동 파일럿

- 페르소나 character sheet 확정 (말투, 금칙어, 활동 시간대) — [06-data-model.md](06-data-model.md)
- 레퍼런스 이미지/UGC 소싱 및 권리 관계 정리 (계약서, 동의 확보)
- 사용할 SNS 플랫폼 및 공식 API 가용 범위 조사
- 개인사업자(소상공인 지위) 등록 — 법인 설립 없이 세금 부담 최소화 ([15-entity-and-tax.md](15-entity-and-tax.md))
- **사람이 직접 운영하는 수동 파일럿 실행** — 자동 생성 파이프라인·자동 응답 없이, 1~2개월간
  월 1만원 미만으로 "이 페르소나 컨셉이 반응을 얻는가"를 검증 ([13-pilot-plan.md](13-pilot-plan.md))
- **통과 기준**: 참여율·팔로워 증가·DM 반응 추세 확인 + 운영 지속가능성 판단 — 이 기준을 통과해야
  Phase 1 이후 단계에 투자할 근거가 생김 ([11-recommended-sequence.md](11-recommended-sequence.md))

## Phase 1 — 대화 자동화 반자동 도입

- 단일 플랫폼 DM 수집 → 사람 검수 후 발송 (완전 자동 발송 이전 단계)
- 휴먼라이크 스케줄러의 지연/동시성 로직만 우선 검증 ([01-reply-automation.md](01-reply-automation.md))
- 목표: "자동 생성된 답변을 사람이 승인만 누르는" 반자동 운영

## Phase 2 — 이미지 모델 트레이닝 & 기본 생성

- 1개 핵심 페르소나로 LoRA 학습 파이프라인 구축
- ComfyUI 워크플로우로 정지 이미지 생성 (표정 변화 우선)
- QC 게이트(수동 전수 검수)로 품질 기준 확립

## Phase 3 — 콘텐츠 파이프라인 확장

- 의상/메이크업 체인지 워크플로우 추가
- 정지 이미지 → 숏폼 영상 파이프라인 추가
- 자동 QC 체크(정체성 유사도 등) 도입, 수동 검수는 샘플링으로 축소
- 매출이 안정화되면 조지아 LLC + Virtual Zone 지위로 전환 검토 (법인세·VAT 0%, [15-entity-and-tax.md](15-entity-and-tax.md))

## Phase 4 — 얼굴교체·모션 리타겟팅 파이프라인

- 권리 확인 게이트 프로세스 확정 (법률 검토 포함) — UGC(얼굴교체)와 드라이빙 영상(모션 리타겟팅) 둘 다 적용
- 소량 UGC로 얼굴교체 엔진 검증 ([04-faceswap-ugc.md](04-faceswap-ugc.md))
- 소량 드라이빙 영상으로 모션 리타겟팅 엔진 검증 ([14-motion-reenactment.md](14-motion-reenactment.md))
- 두 엔진 모두 영상 시계열 일관성/모션 자연스러움 품질 기준 확립 후 배치 규모 확대

## Phase 5 — 완전 자동화 통합

- 대화 자동화: 사람 승인 단계 제거, 완전 자동 발송 (안정성 확인된 경우에 한함)
- 콘텐츠 자동화: QC 통과 에셋의 자동 포스팅 연동 ([05](05-auto-posting.md))
- 게시물 반응(댓글/DM)이 다시 대화 자동화로 유입되는 순환 구조 완성

## Phase 6 — 다중 페르소나 스케일 아웃

- 페르소나별 모델/캐릭터 시트를 템플릿화해 신규 페르소나 온보딩 시간 단축
- GPU 자원 스케줄링을 페르소나 수 증가에 맞춰 큐 기반으로 재설계
- 페르소나 간 콘텐츠/대화 스타일 교차 오염 방지 검증

## 진행 순서에 대한 권장 사항

- **MVP를 통과하지 못하면 Phase 1 이후에 투자하지 않음** — 파이프라인 개발비·하드웨어 구매비를
  전혀 쓰지 않고 컨셉 실패를 알 수 있는 것이 MVP의 핵심 가치
- Phase 1과 Phase 2는 완전히 독립적이므로 동시 착수 가능
- Phase 4(얼굴교체·모션 리타겟팅)는 법률/권리 검토가 선행되지 않으면 시작하지 않음
- Phase 5(완전 자동 발행)는 각 축이 최소 한 번 이상의 반자동 운영 사이클을 거친 뒤 진입
