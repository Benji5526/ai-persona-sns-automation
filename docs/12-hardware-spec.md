## 2. GPU 티어별 비교 — VRAM이 기준선

이 프로젝트가 요구하는 VRAM 최소선([09-llm-serving.md](09-llm-serving.md), [02-model-training.md](02-model-training.md) 근거):
SDXL LoRA 12~16GB, FLUX급 LoRA 16~24GB, LLM 7B~13B LoRA 파인튜닝(4bit) 16~24GB.

| 노트북 GPU | VRAM | 이 기준 충족 여부 | 비고 |
|---|---|---|---|
| RTX 4060/4070 노트북 | 8GB | ✗ | SD 1.5급만 무난, SDXL부터 버거움 |
| RTX 4080 노트북 | 12GB | △ | SDXL LoRA 하한선, FLUX·LLM 파인튜닝은 부족 |
| RTX 4090 노트북 | 16GB | ○ | SDXL·FLUX 가능, LLM 7B급 파인튜닝 가능 |
| **RTX 5090 노트북** | **24GB** | **◎** | 이 프로젝트가 요구하는 모든 VRAM 기준 충족 |

> 노트북용 RTX 5090은 데스크톱 RTX 5090(32GB, GB202, 575W)과 다른 칩(GB203, 10,496코어, 150~175W)입니다.
> VRAM은 충분하지만 연산 속도는 데스크톱 대비 절반 이하로 봐야 합니다 — "돌아간다"와 "빠르다"는 다른 얘기입니다.

## 3. 권장 사양 상세

| 구성 | 사양 | 이유 |
|---|---|---|
| GPU | RTX 5090 노트북 (24GB GDDR7) | 위 표의 유일한 ◎ 등급, 향후 페르소나/모델 확장에도 여유 |
| CPU | Core Ultra 9 275HX/285HX급 | 고사양 GPU 노트북에 기본 탑재되는 라인업, 데이터 전처리·오케스트레이션 병목 방지 |
| RAM | 64GB (여유 시 96GB) | LLM 컨텍스트 + ComfyUI + 백그라운드 프로세스 동시 운용 |
| 저장공간 | NVMe SSD 2TB 이상 | 체크포인트(수 GB) + LoRA + 데이터셋 + 생성물이 빠르게 누적됨 |
| 디스플레이 | 우선순위 낮음 | 이 워크로드엔 무관 — 냉각 성능이 더 중요 |
| 냉각 | 지속 부스트클럭 유지력 확인 (리뷰의 "서스테인드 성능" 항목) | 노트북 특유의 서멀 스로틀링이 장시간 트레이닝 시 체감 성능을 좌우 |
