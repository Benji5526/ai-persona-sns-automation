시스템 개요 — 두 개의 축

페르소나 정의(코어)를 공용 자산으로 두고, 대화 자동화(AXIS A)와 콘텐츠 자동화(AXIS B)가 각각 파이프라인을 구성한다. 콘텐츠 결과물에 달리는 반응은 다시 대화 자동화로 유입되어 순환한다.

실선 = 처리 흐름
점선 = 참조·데이터 제공
상세 시트 참조 번호
분기 · 게이트

SHEET 3 / 4

콘텐츠 자동화 — 3개 독립 엔진 파이프라인

학습된 페르소나 모델은 서로 다른 모델을 쓰는 3개 엔진(생성 · 얼굴교체 · 모션 리타겟팅)으로 소비되어 하나의 QC 게이트를 통과한 뒤 발행된다. UGC/드라이빙 영상 경로는 둘 다 권리확인 게이트를 먼저 통과해야 한다.

권리확인 게이트 (라이선스 필수)
QC 게이트 (밸브 기호)
모션 리타겟팅 엔진 (얼굴교체와 별도 모델)

SHEET 4 / 4

공정표 & 현장 노트

MVP(기반 준비 + 수동 파일럿)를 통과해야 Phase 1 이후에 투자한다. Phase 1–2는 병렬 착수 가능. Phase 4(얼굴교체·모션 리타겟팅)는 법률 검토 선행, Phase 5(완전 자동 발행)는 반자동 운영을 한 차례 거친 뒤 진입한다.
